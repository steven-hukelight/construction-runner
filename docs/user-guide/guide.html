1. Welcome

Construction Runner is the platform your company uses to run sites: who is on site, who is inducted, which RAMS and briefings apply, and the tasks and deliveries for that site only.

There are two products that work together:

  • Web admin — www.construction-runner.com — for Super Admins, Site Admins, Supervisors and Subcontractor admins.
  • Mobile app — Construction Runner on iPhone and Android — for operatives (and for supervisors who also work on site).

Open the public website (construction photography and product overview), then choose Member Login to reach the admin sign-in screen.

Figure 1. Public website — Member Login (top right) opens the admin sign-in page.

Figure 2. Contact page — request a demo or discuss a rollout at www.construction-runner.com/contact

SupervisorWeb + appSame site ticks as Site Admin. Run live attendance and role call, add tasks, review safety. On the app they also get Supervisor Tools.

Site folders. Tasks, RAMS, briefings, site rules and alerts belong to one site. A Site Admin or Supervisor who is ticked for Kidbrooke does not see PWT’s documents, and the other way around — unless you tick both sites.

3. Getting started — web

Sign in

  1. Go to www.construction-runner.com and click Member Login (or open /admin/login).
  2. Enter work email and password. Optionally tick Remember me.
  3. Or use Sign in with Google if your company uses Google accounts.

Figure 3. Construction Runner Admin — Sign in.

Pending approval. After you register you cannot sign in on web or app until a Super Admin (or other approver) approves you. The login screen will say your account is pending approval.
Operatives. If an operative tries the website they see: “Operative web login is a future feature. Please use the mobile app.”

Create an account

From sign-in, click Create account. Two tabs:

  • Join with invite code — Full Name, Work Email, Company Invite Code (from Settings → Company), Set Password, then Submit registration.
  • Request new company — for a brand-new organisation. Pending superuser approval.

Figure 4. Create an account — join with company invite code.

Forgot password

  1. On sign-in, click Forgot password?
  2. Enter the account email and click Send reset link.
  3. Open the email, set a new password, then sign in.

A Super Admin can also send a reset from Users → row menu → Send reset email.

Figure 5. Forgot password — email a reset link.

4. Roles and access

After sign-in, the left sidebar is your map of the product. Super Admins see the full company. Site Admins and Supervisors only see the sites assigned to them. The Dashboard opens with a company snapshot — active sites, who is on site, and open tasks — so you can jump into the work that matters today.

  • Assign the Super Admin role

Site Admins and Supervisors can invite or approve people as Operative only.

5. Sites

Open Sites. Super Admins see every company site. Site Admins and Supervisors see only assigned sites. Status columns use the same soft chips as the rest of the admin (Active / On map / Required).

Figure 6. Illustrated Sites screen (labels match the live admin). Each site is its own folder for documents and tasks.

Add or edit a site (Super Admin)

  1. Click Add New Site (or open a site → Details).
  2. Enter Site Name and address. Set location on the map if needed.
  3. Set Geofence radius (metres) — this is the GPS boundary for mobile Sign In / Sign Out.
  4. Tick Show on mobile map if operatives should see it on the app map.
  5. Tick Induction required for this site if people must complete induction before they can sign in.
  6. Click Save / Save changes.

Row actions include View map, Toggle visible, Toggle active, and Delete site. Open a site to use the Details, Subcontractors and Induction tabs.

6. Users, invites and approvals

Invite someone

  1. Open Users → Invite User.
  2. Enter name, email and role.
  3. For Site Admin or Supervisor, tick every site they should see (they can be on more than one). Click Invite.

Approve a registration

  1. Open Pending approvals. Until you approve, they cannot sign in on web or app.
  2. Choose Assign role: Operative, Supervisor, Site Admin, or Super Admin.
  3. For Supervisor or Site Admin, tick Sites they can access (tick all that apply) — at least one site.
  4. Click Approve or Reject.

Figure 7. Illustrated Pending approvals — assign a role and tick sites before Approve.

Change sites later

On Users, open the row menu for a Site Admin or Supervisor and choose Assign sites…. Tick every site they work on, use Select all / Clear if needed, then Save.

Figure 8. Illustrated Assign sites — multiple sites for Site Admins and Supervisors. Role chips match the live admin.

Other user actions: View profile, Medical records, Set role, Send reset email, Delete user.

Company invite code. Settings → Company shows the code staff use on Create account. Use Regenerate Invite Code if the old code should stop working.

7. Attendance

Open Attendance. Pick a date (or Today). Two tabs:

  • Live — who is signed in. Archives at midnight UK time; pick a past date to view the archive. Use Record attendance for a manual web Sign In / Sign Out (this does not replace GPS check-in on the app).
  • Role Call — fire roll call. Signed in first, signed out on the other sub-tab. Filter by site. Export CSV, Export PDF, Archive & Clear Day.

Figure 9. Illustrated Attendance — Live log plus optional manual Record attendance.

Mobile auto sign-out reasons can appear as geofence exit, left site, or auto sign-out (for example if GPS goes silent for too long).

8. Tasks, deliveries, assets and messages

Tasks

Add Task — Title, Description (optional), Assigned To (multiple people), Site (required), Due date. Super Admins, Site Admins and Supervisors can add tasks. Operatives complete them on the app (Open / In progress / Done).

Deliveries

Add Delivery — Reference, Supplier / Wholesaler, Site, Scheduled At, Notes. Operatives can submit proof of delivery and load photos on the app.

Assets

Add equipment, assign to operatives, upload inspection evidence. Operatives see My Assets on the app.

Messages

Open Messages. You only see conversations you are in. Click New, then pick the people who should receive the thread. You can optionally choose Broadcast to all company users when everyone needs the same message. Reply in the thread.

Always pick the site. When you create a task, delivery, RAMS, briefing or alert you will be asked for a site. That item stays in that site only.

10. Induction and missing info

Missing Info lists people who still need emergency contact or medical details filled in. Use it to chase incomplete profiles before they arrive on site.

Induction is stored per site and expires 365 days after completion. On a site, the Induction tab shows Inducted, Expired, Induction Required, and lets an admin mark complete or reset.

When someone inducts on the app they: read Induction safety (company pack) → acknowledge RAMS → confirm site rules → Complete induction.

Admins who go to site should be inducted like everyone else (see Profile → Induction on the app, or the site Induction tab on web).

Figure 11. Illustrated My Inductions on the app — start induction on a new site here. Statuses: Not Started, Completed, Expired.

11. Mobile app for operatives

Download Construction Runner from the App Store or Google Play. Sign in with the same email and password. Registration in the app also needs a company invite code and then admin approval.

Figure 12. Illustrated Home tab — Check In / Out, tasks and briefings. Bottom tabs: Home, Safety, Deliveries, Assets, Messages, Tasks.

Sign in on site

  1. Home → Check In / Out.
  2. Tap Select site and choose the site.
  3. Wait until the map shows Inside Site Boundary.
  4. If the site requires induction, complete Site induction (Read site safety information → Acknowledge RAMS → Confirm site rules → Complete induction).
  5. On RA/MS Acceptance tap Accept & Sign In.
  6. Tap Sign In. To leave, tap Sign Out or walk out of the geofence (auto sign-out).

Figure 13. Illustrated Check In / Out map. You must be inside the boundary to Sign In. Leaving the site signs you out automatically.

Location must be Always. On iPhone, Settings → Construction Runner → Location → Always (not While Using). On Android, set Location to Allow all the time. “While Using” or “Allow Once” will not sign you out after you leave the site.

Safety and other tabs

  • Safety: Briefings (Sign & acknowledge), RAMS, Site Rules, Safety checklist, Alerts, Near Miss (New report → Submit Report), COSHH.
  • Profile (⋮ menu): Personal Info, My Info, My Inductions, Settings, Sign Out.
  • Optional: Face ID / biometric login and app lock in Settings.
My Inductions vs Select site. Use My Inductions to start induction on a site you have not done yet. Use Select site on the map for today’s attendance. Induction still blocks Sign In when the site requires it and you have not completed it.
Connection and GPS. Sign In needs a live connection and location. The web admin does not offer an Offline queue screen.

12. Subcontractors

  1. Main contractor: Subcontractors → Invite Subcontractor → choose Site to link → Generate invite code → copy the code.
  2. Partner opens www.construction-runner.com/join — Join as subcontractor — enter code and email → Continue, then sign in once approved.
  3. Subcontractor admins use Operative Onboarding to invite their own people and upload documents.

13. Settings, profile and privacy

Settings tabs: Personal Information, Company (name, address, logo, invite code), Notifications, Security (Change Password, Two-Factor Authentication, Session Timeout), Display, Data & Privacy (Export Data, Delete Account).

Profile tabs: Personal, Activity, Certification & Training, Medical History, Induction, Privacy & Data. Need help? The sidebar links to info@construction-runner.com. Privacy policy: /legal/privacy-and-security

Notifications in the top bar clear when you close the panel after reading them (you do not have to click each item).
