Always location required

Background location keeps you accurate. So you are never left signed in after you leave site.

✓ Only used to detect when you cross the site boundary.
✓ We do not track your movement or store any location history.
✓ Uses low-power presence detection — no continuous GPS.
If your exit isn't detected, you'll be auto signed out and marked absent.

Apple shows two screens. First tap Allow While Using the App. Then tap Change to Always Allow.

Turn location to Always

Do this once. Sign In will not work properly until location is Always (iPhone) or Allow all the time (Android).

  1. Tap Continue when the app asks.
  2. iPhone: Allow While Using, then Change to Always Allow.
  3. Android: Permissions → Location → Allow all the time.
  4. Come back to the app and Sign In.

While Using or Allow Once cannot sign you out after you leave site.
