Check In / Out

Open Home → Check In / Out. Choose the site, wait until the map shows you are inside the blue boundary, then tap Sign In.

  1. Set Location to Always (iPhone) or Allow all the time (Android).
  2. Complete site induction if the site requires it.
  3. Accept RAMS, then Sign In.
  4. Leaving the geofence signs you out automatically.
